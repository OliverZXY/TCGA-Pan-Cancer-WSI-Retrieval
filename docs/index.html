TCGA Pan-Cancer Multi-Center Datasets

A public index of TCGA pan-cancer, multi-center diagnostic slides and pre-computed feature paths, supporting center-aware retrieval evaluation, out-of-distribution generalization, and continual learning across cancers, organs, hospitals, and countries. Introduced in Adapting pathology foundation models for continual cross-center WSI retrieval (Zhu et al., Medical Image Analysis, 2026) , with code available at CCBHIR .

Manifest schema

Slide-level fields designed for studies

Identity

uuid, slide_id, case_id, file_name

Labels

project_id, primary_site, site_id, disease_id

Feature path

sub_path points to the corresponding pre-computed .pth feature file.

Center metadata

data_center, task_id, and tissue source site fields describe the center split and origin.
